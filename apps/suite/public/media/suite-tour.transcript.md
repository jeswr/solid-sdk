# A tour of the Solid Suite

## Your apps, your pod

This is the Solid Suite. It has the everyday apps you would expect, for files, documents, tasks, calendars and contacts. The difference is where your data lives.

Today, every app keeps its own copy of your data, on its own servers, under its own rules. Solid turns that around. Your data lives in a pod that you control, and apps ask to use it.

## Getting started

You can sign in with any Solid pod provider. For this walkthrough, we'll use the built-in demo pod, which lives entirely in your browser.

One click, and we're in, as Alice, a fictional demo user.

## Home

Home is the front door to your pod. It shows what's stored there, sorted into everyday categories like documents, calendar and media.

And it keeps one question in view at all times: who else can see this?

## Drive

Drive works the way you'd expect. Folders, uploads, search, and a list or grid view.

Any file or folder can be shared, moved, starred, or renamed, with keyboard shortcuts for each.

Files open in a preview, read straight from the pod.

## Docs

Docs is a full word processor. Let's start a new document.

As you type, it saves to your pod. Not as a file locked inside one app, but as open, linked data that other apps can read too.

Close the tab, come back on another device, and it's all still there, because it was never stored anywhere else.

## Tasks

Tasks is a simple to-do list. Press Q anywhere to add one.

Type naturally. Tasks picks up the word tomorrow and sets the due date for you.

## Calendar and contacts

Calendar has day, week, month and agenda views, with separate calendars for personal and work.

Contacts keeps your address book in the same pod, with labels, imports, and a tool that finds and merges duplicates.

## And more on the way

Photos, Music and Money are earlier, but they already run on the same pod.

Your music library and playlists.

And your accounts and spending, with no bank connection needed.

## Who can see what

Because everything is in one place, one page can show everyone who has access to your data.

Here, some files are open to anyone with the link. One click makes them private again.

Bob has had access to some files since October. You can see exactly what he can reach, and take it back at any time.

## Built in the open

Underneath, the suite is built on open standards: Solid, and the W3C's work on Linked Web Storage.

The code is open source, as more than seventy reusable packages, so anyone can build their own apps on the same pods.

Next comes a personal agent that asks before it acts, mobile apps, and more apps reaching feature parity with the tools you use today.

Try the demo for yourself at solid dash suite dot vercel dot app.
