# Local Solid pod plugin (prepared only)

The JSON descriptors in this directory are authored by Codex GPT-6.1-Sol.
This plugin declares one stdio server and no hooks. Set `SOLID_MCP_POD_ROOT` in
the launching shell; `SOLID_MCP_READONLY` defaults to `true`. All other settings
belong in the existing private 0600 `~/.config/solid-mcp/config.json` file.
Use `oidcIssuer` with both CSS credentials for discovery, or supply `tokenUrl`.
See the [marketplace README](../../README.md) before configuring or enabling it.
The npm command requires a future distribution; nothing here is published.
