# sst-kmwd — CAL-L7 calendar natural-language quick add

Implemented on `lane/sst-kmwd`. The library is pure TypeScript under
`apps/suite/src/apps/calendar/lib/quickadd/`, with an index barrel, public draft and
error types, README, synthetic unit tests, and its coverage glob in Suite's config.

`parseEventQuickAdd(input, { now, tz })` handles both brief examples, explicit and
relative dates, unambiguous clocks, explicit ends and durations, all-day events,
locations, and daily/weekly/weekday recurrence. Dates use the injected IANA zone.
Unsupported or ambiguous input throws `EventQuickAddError`, preserving the entire
input as its title and reporting original source spans; no partial schedule leaks.
DST gaps/overlaps, duplicate/conflicting fields and unsupported date ranges fail
closed. No default duration is inferred. The bounded grammar and conservative
choices are documented in the library README and `QUESTIONS.md`.
