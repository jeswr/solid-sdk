# MUS-L2 conservative readings

1. **Navigation boundaries** (10-pure-libraries-2; 07 Music parity queue row): the spec does not distinguish manual skip from natural completion or define the exact three-second boundary. Options: repeat-one affects all navigation, or only natural completion. Chosen: `ended` honours repeat-one; manual `skip`/`previous` bypass it. Previous at **>= 3 seconds** restarts; below that it selects the preceding entry. Repeat-all wraps; previous at the first entry otherwise restarts. Skip/completion past the end with repeat off clears the current entry. Navigation asks the caller to seek to zero; the pure reducer owns no audio element or clock.
2. **Shuffle and edits** (10-pure-libraries-2 MUS-L2): options include pinning current at its index or moving it to the front; restoring the original order or preserving manual moves. Chosen: seeded Fisher-Yates over all other entries, current pinned at its index. Disabling restores the saved order, including additions/removals. Moves while shuffled affect the displayed order only. Play-next also inserts after current in the saved order; add-to-end appends to both. Removing current selects its displayed successor, otherwise predecessor. Unique queue-entry IDs allow repeated tracks with different entry IDs.
3. **Playlist dialects and encoding** (10-pure-libraries-2 MUS-L2 fail-closed rule): options include guessing legacy encodings/local paths and ignoring unknown extensions, or supporting a documented subset. Chosen: callers supply already-decoded Unicode text for both M3U/M3U8. Support basic M3U, extended M3U with whole-second `#EXTINF`, and PLS v2. Reject fractional durations, HLS/unknown extension directives, unsupported PLS keys/sections, duplicate fields, inconsistent counts, local/Windows paths, non-HTTP(S) URLs and credentials. Resolve relative URL references against an explicit absolute HTTP(S) base IRI. Unknown duration is -1 on disk and null in memory; missing title is the empty string. Output uses absolute URLs and LF. No lossy encoding guesses or path conversion.
